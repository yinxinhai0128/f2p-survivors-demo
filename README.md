# 吸血鬼幸存者 Like 网页游戏 Demo

这是一个用 Phaser + TypeScript + Vite 从零搭建的网页游戏 Demo。当前目标不是美术精修，而是先验证核心玩法是否成立：玩家移动、敌人追踪、自动攻击、经验成长、升级三选一，以及 3 分钟一局的结束条件。

## 运行方式

```bash
npm install
npm run dev
```

打开终端提示的本地地址后即可游玩。

## 为什么选择吸血鬼幸存者 like

吸血鬼幸存者 like 很适合作为低成本 Demo 原型：

- 核心操作极简，玩家只需要移动，学习成本低。
- 成长反馈密集，短时间内能验证“打怪 - 掉落 - 升级 - 变强”的循环是否好玩。
- 内容扩展空间大，后续可以持续增加角色、武器、敌人、地图、词条和局外养成。
- 商业化验证点清晰，复活、双倍收益、成长奖励都可以自然接入。

## 核心循环

当前 Demo 的核心循环是：

1. 玩家使用 WASD 在地图中移动。
2. 敌人从屏幕四周刷新，并持续追踪玩家。
3. 玩家自动攻击最近敌人。
4. 敌人死亡后掉落经验球。
5. 玩家拾取经验，达到阈值后升级。
6. 升级时暂停战斗，出现三选一技能。
7. 玩家通过技能强化继续生存，直到死亡或存活 3 分钟。

## 当前基础数值

- 玩家：100 生命、220 移速、420ms 初始攻击间隔。
- 敌人：24 初始生命、68 初始速度、8 接触伤害。
- 经验：敌人死亡掉落 4 点经验，升级阈值会逐级提高。
- 技能：
  - 攻击速度提升：攻击间隔降低 15%。
  - 子弹数量提升：每次自动攻击额外发射 1 发子弹。
  - 移速提升：移动速度提高 12%。
  - 回血：立即恢复 35 点生命。

## 美术策略

第一版全部使用几何图形占位：

- 玩家：蓝色圆形。
- 敌人：红色方块。
- 子弹：黄色小圆点。
- 经验球：绿色小圆点。

这样可以把开发重点放在手感、节奏、数值和商业化入口验证上。等核心体验稳定后，再用 AI 生成角色、怪物、技能特效、UI 图标和地图贴图。

## AI 如何提效

AI 在这个项目中适合承担：

- 快速生成可运行的 Phaser + TypeScript 项目骨架。
- 迭代核心玩法逻辑，例如自动攻击、刷怪、经验升级、技能选择。
- 批量生成占位美术、技能图标、怪物变体和 UI 草图。
- 辅助调整数值曲线，快速尝试不同战斗节奏。
- 生成 README、策划说明、商业化方案和后续迭代任务列表。

## 商业化设计

当前 Demo 预留了三个 mock 入口：

- 广告复活：死亡后可模拟观看广告并恢复部分生命。
- 双倍经验：点击后切换经验加倍状态，用于验证激励广告或限时增益入口。
- 战令 / 成长奖励：展示一个预留弹窗，后续可接入每日任务、等级奖励和付费成长线。

这些入口暂时不接真实广告或支付 SDK，只用于验证界面位置、交互意图和玩家是否愿意点击。

## 后续扩展

建议按这个顺序推进：

1. 增加武器差异：穿透弹、环绕球、范围爆炸、链式闪电。
2. 增加敌人类型：快速敌人、坦克敌人、远程敌人、精英怪。
3. 做局内掉落：磁铁、回血、金币、短时间无敌。
4. 做局外成长：角色升级、天赋树、装备、收藏图鉴。
5. 接入真实商业化：广告 SDK、战令任务、每日签到和付费礼包。
6. 替换 AI 美术素材，并加入动画、音效和打击反馈。

## 项目结构

```text
src/
  main.ts
  styles.css
  scenes/
    GameScene.ts
```

主玩法目前集中在 `src/scenes/GameScene.ts`，方便第一阶段快速迭代。后续内容变多后，可以拆分为玩家、敌人、武器、掉落、UI、数值配置等模块。
