# Free-to-Play Survivor Game

> 对标《弹壳特攻队》(Survivor.io) 的网页小游戏 Demo，用于学习 F2P 游戏商业化设计。
> 基于 **Phaser 3 + TypeScript + Vite** 构建。

## 在线试玩

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`

## 操作方式

| 按键 | 功能 |
|------|------|
| W / A / S / D | 移动 |
| 自动 | 攻击最近敌人 |

## 已实现功能

### 核心循环
- **4200×3000 大地图**，摄像机平滑跟随玩家
- **自动攻击**：子弹飞向范围内最近敌人
- **经验收集**：击杀掉落绿色经验球，靠近自动吸取
- **升级三选一**：升级暂停游戏，3 张技能卡牌可选

### 5 种敌人类型
| 类型 | 外观 | 特点 |
|------|------|------|
| 普通 | 红色方块 + 眼睛 | 基础属性 |
| 快速 | 橙色三角 | 1.7× 速度，0.5× 生命 |
| 坦克 | 暗红方块 + 金边 | 3× 生命，0.5× 速度 |
| 精英 | 紫色方块 + 白边 | 2.2× 生命，1.2× 速度 |
| BOSS | 3 种外观随机 | 75× 生命，激光 + 散射弹幕 |

### BOSS 战（每 55 秒）
- **三种外观**：恶魔（双角尖刺） / 巨眼（触手瞳孔） / 死神（骷髅荧光眼）
- **激光攻击**：1.5 秒预瞄追踪 → 无限延伸光束
- **散射弹幕**：18 发/轮 × 1~5 轮连发，无限射程
- **HP 血条**：屏幕上方实时显示

### 怪物大潮
- 每 **35 秒**触发一次，持续 **10 秒**
- 大潮期间刷怪速度 ×4，屏幕显示倒计时

### 7 种技能 × Lv.5 质变

| 技能 | Lv.1~4 | Lv.5 质变 |
|------|--------|----------|
| 攻击速度 | 间隔 -15% | **狂暴攻势**：间隔减半 + 子弹+1 |
| 子弹数量 | +1 发 | **穿透射击**：子弹穿透 3 个敌人 |
| 伤害提升 | +6~14 | **致命一击**：30% 暴击，伤害 ×2 |
| 移速提升 | +12% | **烈焰轨迹**：移动留下火焰灼伤 |
| 回血 | 恢复 30~50 | **血之契约**：生命上限 +50，秒回 2 血 |
| 环绕护体 | 范围伤害 | **三星环绕**：3 重环绕，伤害翻倍 |
| 腐蚀光环 | 近身伤害 | **凋零光环**：范围翻倍 + 减速 40% |

- 已质变技能不再出现在升级选项中
- Lv.4→Lv.5 卡牌金色边框 + 质变预览 + 全屏特效

### 掉落道具
| 道具 | 外观 | 概率 | 效果 |
|------|------|------|------|
| 磁铁 | U 型红蓝马蹄铁 | 2% | 瞬间吸取全屏所有经验/道具 |
| 血瓶 | 玻璃瓶 + 2/3 红色血液 | 2% | 恢复 25 生命 |
| 金币 | 金圆光泽硬币 | 12% | 1~5 金币（右上角累计显示） |

### 商业化挂件（Mock）
- **广告升级**：自选技能直升 Lv.5 质变（测试用）
- **双倍经验**：开关切换
- **战斗通行证**：展示面板
- **广告复活**：阵亡后恢复 50% 生命（每局 1 次）

### 游戏结束
- 倒计时 3 分钟胜利 / 阵亡失败
- 展示等级、击杀、金币、存活时间
- 复活 / 重新开始按钮

## 技术架构

```
src/
├── main.ts              # Phaser 配置入口
├── styles.css           # 全局样式
└── scenes/
    └── GameScene.ts     # 主游戏场景（~1900 行，全部逻辑）
```

- 无 UI 框架依赖，纯 Phaser API
- 程序化纹理生成（Graphics API，无外部图片资源）
- 所有界面元素 `setScrollFactor(0)` + `setDepth()` 实现 HUD
- Arcade Physics 物理引擎
