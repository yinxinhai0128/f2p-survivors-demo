# AI Survivor Demo

一个用于面试展示的网页小游戏 Demo，使用 Phaser + TypeScript + Vite 实现。

项目目标不是先追求美术精致，而是快速验证一个《吸血鬼幸存者 like》的最小可行核心循环：玩家移动、敌人追踪、自动攻击、击杀掉落经验、拾取升级、3 分钟一局结算，并预留商业化入口。

## Quick Start

```bash
npm install
npm run dev
```

打开终端提示的本地地址，一般是：

```text
http://127.0.0.1:5173/
```

生产构建：

```bash
npm run build
```

## Tech Stack

- Phaser: 游戏渲染、输入和物理系统
- TypeScript: 游戏逻辑类型约束
- Vite: 本地开发与打包

## Current Features

- WASD 控制玩家移动
- 玩家使用圆形几何图形占位
- 敌人从屏幕四周随机刷新
- 敌人自动追踪玩家
- 敌人接触玩家造成伤害
- 玩家自动攻击最近敌人
- 子弹命中敌人后造成伤害
- 敌人死亡后掉落绿色菱形经验点
- 玩家靠近经验点后自动吸收
- 拾取经验后升级
- 一局持续 3 分钟
- 血量归零失败，倒计时结束胜利
- 结算页展示存活时间、击杀数、等级、获得经验
- 支持重新开始
- 商业化 mock：
  - 观看广告复活
  - 双倍经验奖励
  - 成长战令入口

## Why Vampire Survivors-like

选择《吸血鬼幸存者 like》作为面试 Demo，主要因为它适合低成本验证完整玩法闭环：

- 操作简单，玩家只需要移动，学习成本低。
- 反馈密集，击杀、掉落、吸收、升级能在很短时间内形成正反馈。
- 系统扩展空间大，可以继续加入武器、技能、敌人、局外成长和关卡变化。
- 商业化入口自然，复活、双倍奖励、战令和成长基金都能和玩法节奏结合。
- 适合展示 AI 辅助开发能力，从玩法原型、数值迭代、UI mock 到素材生产都可以逐步接入 AI。

## Core Loop

```text
移动躲避敌人
  -> 自动攻击最近敌人
  -> 击杀敌人
  -> 掉落经验
  -> 拾取经验
  -> 升级变强
  -> 面对更高压力的敌人
  -> 死亡或存活 3 分钟后结算
```

这个循环的目标是让玩家在很短时间内感受到“变强”和“压力提升”的节奏。

## Monetization Mock

当前 Demo 不接入真实广告或支付 SDK，只做产品展示和交互预留：

- 广告复活：失败后显示“Watch Ad to Revive”，模拟激励视频复活。
- 双倍经验：结算页显示“双倍经验奖励”，模拟激励广告奖励。
- 成长战令：主界面右上角显示 Battle Pass 入口，展示免费奖励、高级奖励、等级进度和解锁按钮。

这些入口用于说明：项目不仅验证玩法，也考虑了后续商业化结构。

## How AI Helps

AI 在这个项目中可以提升以下环节的效率：

- 快速生成 Phaser + TypeScript + Vite 项目骨架。
- 拆分玩家、敌人、子弹、经验、刷怪、升级、商业化 mock 等模块。
- 辅助调试玩法问题，例如子弹命中、击杀掉落、经验吸收和结算流程。
- 快速生成占位 UI、文档、策划说明和面试展示材料。
- 后续可用于生成角色、怪物、武器、技能图标、特效和背景素材。

## Balance Data

基础数值集中在：

```text
src/game/data/balance.ts
```

当前包括：

- 玩家血量、移速、半径
- 敌人血量、速度、伤害、尺寸
- 武器攻击间隔、伤害、射程、子弹速度
- 经验掉落、升级阈值
- 单局时长

集中配置数值方便后续快速迭代手感和难度。

## Next Steps

建议后续按这个顺序继续扩展：

1. 修复和完善重新开始时的状态重置。
2. 将 `UpgradeSystem` 接入升级流程，做真正的三选一技能界面。
3. 让技能实际影响数值，例如攻速、子弹数量、移速、回血和伤害。
4. 优化子弹命中表现，从延迟扣血升级为碰撞或追踪弹。
5. 增加更多武器类型，例如环绕球、穿透弹、范围爆炸。
6. 增加敌人类型，例如快速怪、坦克怪、远程怪和精英怪。
7. 替换 AI 生成美术素材，加入动画、音效和打击反馈。
8. 接入真实商业化 SDK 或继续完善广告、战令、局外成长 mock。

## Interview Talking Points

面试展示时可以重点讲：

- 为什么先做最小可行核心循环，而不是先做美术。
- 如何用模块划分保证后续可扩展。
- 如何通过 `balance.ts` 快速调参。
- 商业化入口为什么放在失败、结算和主界面。
- AI 在原型、调试、素材和文档中的提效方式。
